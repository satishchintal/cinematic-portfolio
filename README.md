# Satish Cinematic Portfolio

A Next.js 14 + TypeScript + Tailwind cinematic portfolio with cursor/scroll video scrubbing, parallax, smooth scrolling, 3D project cards, experience timeline and draggable certification ring.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

The background video is already included at `public/video/portfolio-background.mp4`.

### Content note
The supplied resume was not found in the available file library. The portfolio data is therefore populated only from the user's available Satish AI DevOps roadmap materials and does not invent employment history or credentials. Replace `src/data/portfolio.ts` with resume-derived facts when the resume is supplied.
